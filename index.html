01 — אודות

קצת עליי

אני סטודנט שנה ב׳ למדעי המחשב במכללה למנהל, ומה שמושך אותי באמת הוא מה שקורה אחרי שהקוד נכתב: איך הוא נארז, נבדק, נפרס ומנוטר. משם הגעתי לעולם ה־DevOps, ומאז אני לומד ובונה בו כל הזמן.

בזמני הפנוי אני מקים סביבות מעבדה ביתיות מעל Docker ו־Kubernetes, כותב פייפליינים אוטומטיים ב־GitHub Actions, מנהל תשתית כקוד עם Terraform ו־Ansible, ומחבר לזה שכבת ניטור מבוססת Prometheus ו־Grafana. אני אוהב לקחת תהליך ידני וחוזר על עצמו ולהפוך אותו למשהו שרץ לבד, עם לוגים ברורים והתראות כשמשהו משתבש.

אני מחפש התמחות או משרת ג׳וניור שבה אוכל לתרום לצוות תשתיות, ללמוד ממהנדסים מנוסים, ולהמשיך לגדול לכיוון הנדסת פלטפורמה.

03 — פרויקטים

על מה עבדתי

פרויקטים אישיים ומעבדתיים שבהם תרגלתי את מחזור החיים המלא — מבנייה ועד ניטור.

  • 01

    פייפליין CI/CD מקצה לקצה

    פייפליין מלא שמריץ בדיקות אוטומטיות בכל בקשת מיזוג, בונה אימג׳ Docker רב־שלבי, דוחף אותו ל־Registry ומבצע פריסה אוטומטית לסביבת בדיקות — כולל שער איכות שחוסם מיזוג כשהבדיקות נכשלות.

    • GitHub Actions
    • Docker
    • Bash

  • 02

    פריסת מיקרו־שירותים ל־Kubernetes

    אריזה של אפליקציית מיקרו־שירותים ל־Helm charts ופריסה לאשכול מקומי: הגדרת Ingress, בדיקות בריאות, מגבלות משאבים והתאמת קנה מידה אוטומטית לפי עומס.

    • Kubernetes
    • Helm
    • Nginx

    סביבת ענן כקוד
